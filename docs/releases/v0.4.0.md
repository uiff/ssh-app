**Keyway 0.4.0** adds optional two-factor sign-in.

## New: two-factor sign-in (optional)

- **Off by default.** Turn it on in Settings › Two-factor sign-in. Scan the QR code with an authenticator app (Aegis, Microsoft Authenticator, Google Authenticator …) or type the key, confirm with a code and your password.
- **Works fully offline.** The app and Keyway compute the 6-digit code from the shared key and the clock. The setup dialog shows the server time, and a code that fits another time gets a clear hint with the offset in minutes (handy for a Raspberry Pi without a battery-backed clock).
- **10 one-time backup codes** for when your phone isn't at hand. Resetting the password with the recovery key turns two-factor sign-in off.
- **The vault unlocks only with password and code.** Codes can't be reused. From 10 wrong codes in a row, codes from the app are blocked for 15 minutes, and each further block doubles (up to 24 h); backup codes keep working. You are warned at your next sign-in from 3 wrong codes on, and the log warns from 5.
- The setting is stored encrypted and travels with backups.
